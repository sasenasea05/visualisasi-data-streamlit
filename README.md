# 📊 Dashboard Visualisasi Data & Analisis Interactive

Proyek ini merupakan aplikasi web interaktif berbasis **Streamlit** untuk analisis dan visualisasi data. Dashboard ini dirancang untuk memberikan wawasan (insights) bisnis, analisis tren, dan pemantauan operasional secara terintegrasi.

🔗 **Live Demo / Web Application**:  
[https://visualisasi-data-app-8kxegcqxa7buglcrsx9hvd.streamlit.app](https://visualisasi-data-app-8kxegcqxa7buglcrsx9hvd.streamlit.app)

---

## 🛠️ Fitur & Tampilan Dashboard

Aplikasi ini mencakup beberapa modul analisis:
- **Analisis Penjualan & Operasional (`app.py`)**: Visualisasi performa penjualan, korelasi variabel bisnis, dan KPI utama.
- **Analisis Pengamatan Cuaca (`app_kasus2.py`)**: Monitoring tren parameter cuaca harian dan pola fluktuasi lingkungan.
- **Analisis Profil Mahasiswa (`app_kasus3.py`)**: Analisis demografi, distribusi akademik, dan metrik mahasiswa.

---

## 🚀 Teknologi & Depedensi yang Digunakan

- **Bahasa Pemrograman**: Python 3.10+
- **Framework Web**: [Streamlit](https://streamlit.io/)
- **Visualisasi Data**: Plotly / Matplotlib / Seaborn
- **Pengolahan Data**: Pandas, NumPy
